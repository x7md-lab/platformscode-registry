# كود المنصات

سجل shadcn لمكونات بلغة تصميم «كود المنصات» — مبنية فوق Base UI و‏framer-motion، باستخدام React. ثبّت أي مكون عبر `shadcn add` مع رابط ملف JSON الخاص به.

المكونات مرتّبة حسب تصنيفات [دليل كود المنصات](https://design.dga.gov.sa/guidelines/components)، وواجهات الخصائص تحاكي حزمة `platformscode-react`.
