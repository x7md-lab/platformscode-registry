# كود المنصات

سجل shadcn لمكونات بلغة تصميم «كود المنصات» — مبنية فوق Base UI و‏framer-motion، باستخدام React. ثبّت أي مكون عبر `shadcn add` مع رابط ملف JSON الخاص به.

## شريط التنقل العلوي

يُعد شريط التنقل العلوي مكونًا أساسياً في نظام التصميم حيث يوجه المستخدمين عبر هيكل الموقع الإلكتروني. يظهر عادةً في الجزء العلوي من كل صفحة.
